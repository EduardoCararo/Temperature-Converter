# 🌡️ Temperature Converter

A simple and intuitive temperature converter built using HTML, CSS, and JavaScript. This web app allows users to input a temperature in Celsius and convert it to Fahrenheit and Kelvin instantly.

## 🚀 Live Preview

Enter a temperature in Celsius, click "Convert", and see the result in Fahrenheit and Kelvin.

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript  

## 📄 Features

- Input for Celsius temperature
- Automatic conversion to Fahrenheit and Kelvin
- Input validation with alert if empty
- Clean and responsive visual layout

## 📁 Project Structure
/temperature-converter
│
├── index.html # HTML structure
├── style.css # CSS styles
└── script.js # JavaScript logic

## 🧠 Conversion Logic

- **Fahrenheit:** `(Celsius × 9/5) + 32`
- **Kelvin:** `Celsius + 273.15`

## 🎯 Purpose

This project was created for educational purposes, to practice basic web development concepts such as DOM manipulation, CSS styling, and JavaScript logic.
